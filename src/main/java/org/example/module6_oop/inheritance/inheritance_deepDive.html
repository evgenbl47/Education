1. Что такое Наследование (Inheritance)?

Представь, что ты создаешь игру. У тебя есть Воин, Маг и Лучник. У всех них есть здоровье, имя и умение двигаться. Писать эти поля три раза — скучно и неправильно (нарушает DRY).

Мы создаем общего Родителя (Superclass), а остальные будут его Детьми (Subclass).

📂 Person (Родитель) └── 📂 Employee (Ребенок) ├── 📂 Manager └── 📂 Intern

В Java это делается через ключевое слово extends.

class Person {
    protected String name; // protected виден детям, но скрыт от чужих

    public void walk() {
        System.out.println(name + " идет");
    }
}

class Employee extends Person { // Наследование
    private int employeeId;

    public void work() {
        System.out.println(name + " работает"); // name доступен!
    }
}
⚠️ Важно: В Java нет множественного наследования классов (класс не может иметь двух родителей). Но интерфейс мы изучим позже.

2. Ключевое слово super

Иногда нужно обратиться к родителю. Например, вызвать его конструктор или переопределенный метод.

  • super() — вызов конструктора родителя (должен быть первой строкой).
  • super.method() — вызов метода родителя.
class Employee extends Person {
    public Employee(String name, int id) {
        super(name); // Вызываем конструктор Person
        this.employeeId = id;
    }
}

3. Переопределение методов (Overriding)

Ребенок может изменить поведение родителя. Например, все Звери издают звук, но Собака лает, а Кот мяукает.

Используем аннотацию @Override. Это сигнал компилятору: "Я точно меняю метод родителя!".

class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Гав!");
    }
}

4. Полиморфизм (Polymorphism)

Способность объекта принимать разные формы. Самая частая форма: Ссылка типа Родитель указывает на Объект типа Ребенок.

Animal myPet = new Dog(); // Полиморфизм!
myPet.makeSound(); // Вызовется метод Dog ("Гав!"), а не Animal

Зачем это нужно? Ты можешь создать массив Animal[] и хранить там и собак, и котов, и вызывать у них makeSound(), не заботясь о конкретном типе.

5. Иерархия и доступ (Access Modifiers)

Для наследования чаще всего используем protected для полей, которые должны видеть дети.
