🐾 Practice: Inheritance & Casting (Animals)

Закрепляем тему на примере иерархии животных.

🎯 Цель задачи

Создать базовый класс Animal и двух наследников: Dog и Cat. Отработать:

  • ✅ extends — наследование
  • ✅ super(...) — вызов конструктора родителя
  • ✅ @Override — переопределение методов
  • ✅ Полиморфизм — массив Animal[]
  • ✅ instanceof + casting — вызов уникальных методов

1. Иерархия классов

    🐕 Animal (Базовый класс)
    /           \
    /             \
    🐕 Dog          🐱 Cat
    (Наследник)     (Наследник)

2. Базовый класс Animal

public class Animal {
    protected String name;       // Имя животного
    protected int age;            // Возраст в годах
    protected String color;       // Цвет шерсти

    public Animal(String name, int age, String color) {
        this.name = name;
        this.age = age;
        this.color = color;
    }

    public String getType() {
        return "Animal";
    }

    public void makeSound() {
        System.out.println("Some animal sound");
    }

    public void showInfo() {
        System.out.println("Animal: " + name +
                          ", age: " + age +
                          ", color: " + color);
    }
}

3. Класс Dog (наследник)

public class Dog extends Animal {
    private String breed;         // Порода собаки
    private boolean isTrained;    // Обучен ли

    public Dog(String name, int age, String color,
               String breed, boolean isTrained) {
        super(name, age, color);  // 👈 ПЕРВАЯ СТРОКА!
        this.breed = breed;
        this.isTrained = isTrained;
    }

    @Override
    public String getType() {
        return "Dog";
    }

    @Override
    public void makeSound() {
        System.out.println("🐕 Woof! Woof!");
    }

    @Override
    public void showInfo() {
        System.out.println("🐕 Dog: " + name +
                          ", age: " + age +
                          ", breed: " + breed +
                          ", trained: " + isTrained);
    }

    public void fetch() {
        System.out.println("🎾 Dog brings the ball back!");
    }
}

4. Класс Cat (наследник)

public class Cat extends Animal {
    private boolean isIndoor;     // Домашний или уличный
    private int livesLeft;        // Осталось жизней (9 максимум)

    public Cat(String name, int age, String color,
               boolean isIndoor, int livesLeft) {
        super(name, age, color);  // 👈 ПЕРВАЯ СТРОКА!
        this.isIndoor = isIndoor;
        this.livesLeft = livesLeft;
    }

    @Override
    public String getType() {
        return "Cat";
    }

    @Override
    public void makeSound() {
        System.out.println("🐱 Meow! Meow!");
    }

    @Override
    public void showInfo() {
        System.out.println("🐱 Cat: " + name +
                          ", age: " + age +
                          ", indoor: " + isIndoor +
                          ", lives: " + livesLeft);
    }

    public void scratch() {
        System.out.println("🛋️ Cat scratches the furniture!");
    }
}

5. Демонстрация полиморфизма

// Массив типа Animal — полиморфизм!
Animal[] pets = new Animal[3];
pets[0] = new Animal("Generic", 5, "Gray");
pets[1] = new Dog("Rex", 3, "Brown", "Labrador", true);
pets[2] = new Cat("Murka", 2, "Black", true, 7);

// Вызов showInfo() — каждый объект покажет свою версию
for (Animal a : pets) {
    a.showInfo();      // Динамическое связывание!
    a.makeSound();     // Вызовется версия конкретного класса
}

6. Приведение типов (Casting)

// Чтобы вызвать уникальный метод, нужно приведение!
for (Animal a : pets) {
    if (a instanceof Dog) {
        Dog d = (Dog) a;  // 👈 Приведение
        d.fetch();        // 👈 Теперь доступно!
    }
    if (a instanceof Cat) {
        Cat c = (Cat) a;
        c.scratch();
    }
}
💡 Важно: Без instanceof и casting компилятор не разрешит вызвать fetch() или scratch(), потому что у типа Animal этих методов нет!

8. Чеклист перед началом

  • □ super(...) первой строкой в конструкторах наследников
