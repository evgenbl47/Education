2. Базовый класс Vehicle

Содержит общие поля для всех транспортных средств:

public class Vehicle {
    protected String brand;      // Марка
    protected int maxSpeed;        // Макс. скорость (км/ч)
    protected double weight;       // Вес (кг)

    // Конструктор, геттеры, сеттеры
    // Методы: getType(), move(), showInfo()
}

3. Особенности наследников

Класс Уникальные поля Уникальные методы
Car doors, hasAC openTrunk(), canCarryCargo()
Bike hasBasket, wheelSize ringBell()
Truck cargoCapacity, axles loadCargo(), canCarryCargo()

4. Логические методы (boolean)

Метод canCarryCargo() есть у Car и Truck, но работает по-разному:

// В классе Car:
public boolean canCarryCargo() {
    return doors >= 4;  // 4+ двери = можно везти груз
}

// В классе Truck:
public boolean canCarryCargo() {
    return cargoCapacity > 0;  // Есть грузоподъёмность = можно везти
}

5. Полиморфизм с 3 типами

Vehicle[] garage = new Vehicle[3];
garage[0] = new Car(...);
garage[1] = new Bike(...);
garage[2] = new Truck(...);

for (Vehicle v : garage) {
    v.showInfo();    // Каждый покажет свою версию!
    v.move();        // Каждый поедет по-своему!
}

6. Приведение типа для 3 наследников

for (Vehicle v : garage) {
    if (v instanceof Car) {
        Car c = (Car) v;
        c.openTrunk();
    }
    if (v instanceof Bike) {
        Bike b = (Bike) v;
        b.ringBell();
    }
    if (v instanceof Truck) {
        Truck t = (Truck) v;
        t.loadCargo();
    }
}

7. Валидация в сеттерах (без throw)

⚠️ Помни: Мы не используем throw в этом модуле. Вместо этого устанавливаем значение по умолчанию. 
public void setMaxSpeed(int maxSpeed) {
    if (maxSpeed > 0 && maxSpeed <= 300) {
        this.maxSpeed = maxSpeed;
    } else {
        this.maxSpeed = 100;  // Значение по умолчанию
    }
}

8. Чеклист перед началом

  • Придумай поля для Vehicle (общие для всех)
  • Придумай уникальные поля для Car, Bike, Truck
  • В конструкторах: super(...) первой строкой
  • Переопредели методы с @Override
  • В тесте: массив Vehicle[] + цикл для полиморфизма
  • Для уникальных методов: instanceof + casting
